# Titanic-Survival-Prediction
This repository contains an analysis of the Titanic dataset using data visualization and exploration techniques. The data is cleaned, and insights are gained through univariate, bivariate, and multivariate analysis. Key relationships like survival rates by gender, class, and fare are explored.
This repository contains an in-depth analysis of the Titanic dataset using various data visualization and analysis techniques to explore passenger survival rates. The dataset is cleaned and analyzed using Pandas, Seaborn, and Matplotlib to gain insights into factors influencing survival.

Key Steps:
Data Cleaning: Handling missing values, transforming variables, and preparing the data for analysis.

Exploratory Data Analysis (EDA): Visualizing distributions, relationships, and trends using histograms, boxplots, pairplots, and heatmaps.

Univariate Analysis: Examining individual features like Age, Fare, and Survived to understand their distributions and key statistics.

Bivariate Analysis: Analyzing the relationship between two variables at a time, such as Sex vs. Survival and Pclass vs. Survival.

Multivariate Analysis: Exploring interactions between multiple variables and how they relate to survival using pairplots and 3D plots.

Insights: Key observations on passenger demographics and survival patterns, such as the higher survival rates among women and first-class passengers.

Technologies Used:
Python (Pandas, Seaborn, Matplotlib)

Jupyter Notebooks for analysis

This project provides insights into how various factors such as age, gender, class, and fare impacted survival on the Titanic, which can be used for further modeling and prediction tasks.
